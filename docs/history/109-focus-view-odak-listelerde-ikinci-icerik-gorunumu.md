### 9.109 Focus View ("Odak") — listelerde ikinci içerik görünümü

Listelere **▤ Kart | ▦ Odak** segmentli anahtarı eklendi. **Kart = mevcut sistem, hiç değişmedi** (`PromptCard`/`GeneratorCard`/`WorkflowCard`/`PresetCard`/`RequestCard`, `ContentCard`, `PromptCardFooter`, `FeedGrid`, `PromptGrid`, `RequestList` dosyalarına dokunulmadı — `git diff` ile boş doğrulandı). **Odak = yeni, bağımsız bileşen ailesi** (`src/features/focus/`): kartın bilgi yoğunluğu yerine içeriğin kendisi öne çıkar. Migration yok.
- **Anahtar + kalıcılık:** `features/content/view-mode-store.ts` (modül singleton + `useSyncExternalStore`, sunucu snapshot'ı hep "card" → hydration uyuşmazlığı yok). Öncelik: `?view=focus|card` → `localStorage` (`promptly-view-mode`, yalnızca UI tercihi) → "card". Değişince localStorage + URL'e yazılır (`history.replaceState`, diğer query param'lar korunur; "card"da `view` silinir). `ViewModeSwitcher` (`aria-pressed`, tooltip, odak halkası, mobilde ≥44px hedef, <sm'de yalnız ikon), `SortAndViewControls`/`MobileViewSwitcherRow` (`list-controls.tsx`): ≥sm'de sıralama seçicisinin yanında, dar ekranda chip satırının üstünde kendi satırında.
- **Bağlandığı yerler (opt-in):** Ana Sayfa (`FeedTabs`), Keşfet (`DiscoverFeed`), etiket sayfası (`TagView`) → yeni `FeedItemsView` (Kart'ta eski `FeedGrid`'i olduğu gibi çağırır); `/prompts`, `/requests`, `/generators`, `/workflows`, `/presets` → `ContentListPage`'e `focusKind` prop'u (Kart'ta `renderItems` aynen). Filtre/sıralama/arama/"Daha fazla yükle" aynı state üzerinde çalışır; mod değişince içerik kaybolmaz. Arama sonuçları, Takip Ettiklerim ve profil gridleri Kart-only kaldı.
- **Adaptif render (`focus-card.tsx`, `React.memo`):** görseli olan prompt → `FocusVisualCard` (görsel hero, en-boy 0,8–1,4 arasına kıstırılır; üstte yaratıcı, altta başlık + küçük tür etiketi, aksiyonlar görselin altında; tüm görsel mevcut detay sayfasına gider). Görselsiz prompt → `FocusTextCard` (gerçek prompt metninden ≤280 karakterlik alıntı, 6 satır + solma; ses için dekoratif dalga formu, video için dekoratif film şeridi — `aria-hidden`). Generator → gerçek şemadan parametre adları + sayı; Workflow → görseli varsa görsel, yoksa gerçek adım zinciri (①→②→③); Hazır Ayar → ilk 3 parametre + `+N`; Prompt İsteği → brief (açıklama + yaratıcı yön) + Açık/Kapandı. Beğeni · Yorum · Kaydet gerçek bileşenlerle (`LikeButton`/`CommentCountLink`/`SaveButton`; istekte kaydet yok).
- **Lazy veri:** generator şeması (`fetchGeneratorVersion`) ve workflow adımları (`fetchWorkflowById`) yalnızca kart görünür alana yaklaşınca (`IntersectionObserver`) çekilir, oturum boyunca id başına bir kez (modül önbelleği + in-flight de-dup); yüklenirken skeleton, hata/yoksa listedeki sayılara düşülür.
- **Izgara:** mevcut CSS-columns masonry: mobil 2 / `md` 3 / `xl` 4 sütun.
- **Bilinçli sınırlar:** prompt'ların ses/video varlığı olmadığı için **oynat düğmesi/sahte oynatıcı yok** (yalnız dekoratif ipucu); görselsiz video prompt'unda thumbnail yok; Focus'ta kartın üç nokta menüsü/Paylaş/İstatistik yok (Kart'ta var); giriş yapmış kullanıcı için tercih hesaba yazılmıyor (yalnız tarayıcıda).
