## Davranış
- **Dikey akış (A):** her gönderi bir ekran; yerel `scroll-snap` (`snap-y mandatory`), etkin gönderi = sütunun durduğu ekran (`focusActiveIndex`). Yan yana kaydırma = AYNI gönderinin sonuç görselleri ("1/3 sonuç", `ResultsRow`). Eski küçük resim şeridi, komşu kartlar, ↑ = Bilgi hareketi kalktı.
- **Prompt şeridi (kartın kapalı hâli):** ekranın dibinde ince çubuk; solu kartı açar (dokun ya da yukarı sürükle), sağı türün tek büyük eylemi (`focusFeedPrimaryAction`): prompt → **Kopyala** (panel açmadan, DOLDURULMUŞ metin, kullanım sayılır), açık istek → Yanıtla, ayar paketi → "Bir promptla dene" (`/studio?preset=`), workflow → "Adım adım çalıştır" (`?run=1`), Skill → "Skill'i aç". Resimli/oynatılan promptta tek satır prompt + `{değişken}`ler ikincil renkte; metin sahnesinde değer çipleri ("ton: teknik" / "ton: boş").
- **Kart:** telefonda alttan açılan sayfa — **yarım** (%58: yazar, başlık, "Kanıtlanmış · %93", prompt bloğu, değişken alanları, "Doldurup kopyala" + Studio + Beğeni + Kaydet) → **tam** (%90: küçük başlık + sekmeler Prompt · Yorumlar · Sonuçlar · [Sürümler, yalnız sürüm varsa], Çalıştı mı?, araç, kategori, etiketler, Hazır ayarla dene, Ayrıntıları aç, Space'e ekle). Sürükle yukarı: kapalı → yarım → tam; aşağı: tam → yarım → kapalı (`focusSheetStep/Gesture`, 48 px ya da hızlı fırlatma). Yarımda gönderi üstte küçülür (CSS: sanat yüksekliği `calc(100% - 58dvh + 1.75rem)`), ray/başlık/şerit çekilir, üst çubuk kalır; tamda üst çubuk çekilir. Rayda yorum düğmesi kartı **Yorumlar sekmesinde tam** açar. Diğer türlerde sekmeler: ana sekme (İstek / Adımlar / Parametreler / Skill) + Yorumlar. `Esc` önce yanıtı, sonra kartı, sonra Odak'ı kapatır; kart `aria-modal` olduğu için açıkken ↑ ↓ arkadaki akışı oynatmaz.
- **Değişkenler (tek doğruluk kaynağı `focus-fill.tsx`):** değerler gönderi başına oturumluk tutulur; şerit çipleri, sahnedeki dokunulur sözcükler, seçici, kartın alanları ve "Kopyala" AYNI değerleri okur (`usePromptFill`: `fetchVariablesForPrompt` + `effectiveVariableValues` + `resolvePromptText`; saklanan prompta dokunulmaz). Kopyaladıktan sonra "Çalıştı mı?" yarım kartta da açılır (kopyalayan oy verebilir kuralı sunucudadır).
- **Sahnede doldurma (G2):** metin promptunda `{değişken}` çipine dokununca şeridin yerine seçici (`FocusFillPicker` = `VariableField`: seçenek çipleri / metin / sayı / kaydırıcı / anahtar), metin canlı güncellenir, "Sonraki alan", Tamam, "1 / 2 alan". Masaüstünde aynı dokunuş paneli açıp o alana odaklanır (seçici yalnız telefonda).
- **Görselsiz sahneler:** gönderinin KENDİ içeriği sahnedir, türüne göre sabit koyu zemin (`--color-focus-{text,request,preset,workflow,skill}`, globals.css): metin promptu (mono, dokunulur çipler), istek (metin + yaratıcı yön + durum), ayar paketi (parametre listesi), workflow (adım zinciri), Skill (özet + araçlar). Video/ses çıktısı bulunamayan prompt metin sahnesine düşer.
- **Video/ses:** aynı şerit; resmin ortasında tek oynat/duraklat (ilerleme çubuğu yok), rayın en üstünde ses düğmesi (⋮ menüsündeki anahtarın ikizi).
- **Masaüstü (md+):** sahne ortada 4:5 kart (yazar çipi + sonuç noktaları kartın içinde), sağda KALICI 440 px panel (aynı kart gövdesi: başlık, Beğeni·Yorum·Kaydet·Paylaş satırı, sekmeler, prompt, alanlar, Çalıştı mı?, alt çubukta "Doldurup kopyala" + "Studio'da dene"); gizlenir/geri gelir. ‹ › = sonuçlar (yalnız birden çok sonuç varsa), ↑ ↓ düğmeleri = gönderiler. Klavye: ↑ ↓ / PageUp PageDown / j k gönderi, ← → / h l sonuç, Home End, **P** panel (telefonda kart), **C** kopyala, Esc kapat.
- **"Medya" süzgeci → "Yalnız görselliler", varsayılan KAPALI** (kullanıcıya önerilen ve kabul edilen karar): artık görselsiz gönderi kendi sahnesiyle akışta; açılınca eskisi gibi sunucu `p_has_media` ister (254-* değişmedi).
