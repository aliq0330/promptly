### 9.123 Studio (eski "Üret"): Prompt / Generator / Hazır Ayar kaynaklı deneme alanı

Bölüm 9.121/9.122'deki `/generate` sayfası **Studio** adıyla `/studio` oldu ve ortak bir "kaynak" kavramı kazandı. Bölüm 9.115'te kaldırılan eski Studio'nun (oturum, versiyon, karşılaştırma, kompozisyon) hiçbiri geri gelmedi; amaç yalnızca "kendi API anahtarınla dene, sonucu gör". Migration yok.
- **Kaynak (URL tek doğruluk kaynağı):** Boş / Prompt (`?prompt=<id>`) / Generator (`?generator=<slug>`) / Hazır Ayar (`?preset=<id>`). Sol panelde kaynak çipleri; çip seçici modal açar (`studio-source-picker.tsx`: bellekteki son içerikler ya da başlık/açıklama araması; Hazır Ayar için mevcut `StudioPresetPicker`). Seçim `router.replace` ile URL'e yazılır, yükleme efektleri URL'den çalışır — detay sayfasından gelen bağlantı ile seçiciden gelen aynı yoldan geçer. "Kaldır" çalışma metnini temizler.
- **Prompt:** şablon metin düzenlenebilir çalışma metni olur, `{değişken}` alanları `PromptVariableInputs` ile doldurulur, API'ye `resolvePromptText` sonucu gider (ham `{token}` hiç gitmez). **Generator:** `GeneratorRuntimeForm` + metin kutusu ("Kendi metnin, isteğe bağlı"); prompt `buildGeneratorOutput(...).prompt` (yazılan metin + alan seçimleri). **Hazır Ayar:** önceki davranış. Tür (görsel/metin) kaynağın içerik türünden önerilir; ses/video kaynakta mevcut seçim korunur.
- **Giriş noktaları:** Prompt ve Generator detay sayfalarında Kopyala/Çalıştır yanında, Hazır Ayar detayında eski "Kullan" yerine **"Studio'da aç"** (`OpenInStudioButton`, `features/studio/`). Sidebar öğesi "Studio" (`nav.studio`). Eski `/generate` bağlantıları `LegacyGenerateRedirect` ile query korunarak `/studio`'ya yönlenir. Kod klasörü `features/generate` → `features/studio`.
- **Bilinçli kapsam:** Workflow Studio'ya tam alınmadı (çok adımlı zincir her adımda ayrı API çağrısı, kota/hata yönetimi karmaşası). Geçmiş hâlâ yalnızca bu tarayıcıda (IndexedDB).
- **Tamamlayıcı tur (9.123b):** (1) **Çoklu model karşılaştırma** — "Başka bir modelle de dene" ile ana modele ek en çok 2 satır (sağlayıcı + model; model listesi `fallbackModels`). Aynı final prompt her hedefe, hedef başına `count` kadar paralel gider; farklı sağlayıcı için kendi API anahtarı satırı çıkar (yalnızca bellek/`saveKey`, mevcut "hatırla" tercihi korunur); sonuç kartlarında "Sağlayıcı · model" etiketi. (2) **Düzenle ve tekrar dene** — sonuç kartından o sonucun gönderilen prompt'u çalışma metnine döner (kaynak varsa temizlenir), kutuya odaklanılır. (3) **Workflow adımında "Studio'da aç"** — `workflow-flow.tsx` adım kartında, yayınlanmış Prompt/Generator içerikli adımlarda büyüteç yanında ikon (`/studio?prompt=<id>` / `?generator=<slug>`, slug içerik `href`'inden). Migration yok; TR+EN `studio.compare*`/`studio.editRetry` eklendi.
- **9.123c (cila):** Kaynak seçimi artık zengin `StudioSourceCard` (görsel/ikon, tür, başlık, yaratıcı + zaman, açıklama, etiketler, Değiştir / Orijinali aç / Kaldır); sonuç sütunu sayfayla birlikte kayar (`lg:sticky`), içeriği ekrandan uzunsa normal akışa döner (ResizeObserver); başlık açıklaması ile içerik arasında boşluk; Geçmiş kartları dikey (sonuç üstte, prompt, sağlayıcı·model·zaman, eylemler). Kaynak seçicideki ve hazır ayar notundaki ham `taxonomy.text` etiketi `taxonomyLabel` ile düzeltildi. Migration yok.
- **Doğrulama:** `tsc`/`lint`/`next build --webpack` temiz; ağ taklitli Playwright 20/21 (redirect + query, prompt kaynağı değişken çözümü ve API gövdesi, generator kaynağı gövdesi, seçici akışı, 390px taşma yok). Kalan 1 başarısızlık, `/generate` yönlendirmesi sırasındaki aralıklı React #418 hydration uyarısı (özellikten bağımsız, mevcut). Gerçek Supabase'e ve gerçek AI çağrısına karşı denenmedi. TR+EN eklendi (`studio.*`, `nav.studio`).
