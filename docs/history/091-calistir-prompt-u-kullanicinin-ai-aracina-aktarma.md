### 9.91 "Çalıştır" — prompt'u kullanıcının AI aracına aktarma

Prompt ve Generator'da prompt metninin yanına **[Kopyala] [Çalıştır]**. Promptly hiçbir model çalıştırmaz, API anahtarı tutmaz; yalnızca seçilen aracın sitesini/uygulamasını açar. **Migration yok.**
- **Tek servis:** `src/lib/run-with-ai.ts` — `runWithAI({content, toolId})` (içerik türünden bağımsız düz metin alır; ileride Workflow/Hazır Ayar/İstek sonucu aynı yolu kullanır), `buildRunToolList`, `buildPrefillUrl`, `composeRunText` (prompt + negatif prompt), son kullanılan araç (`localStorage` `promptly-preferred-ai-tool`; hesaba yazılmadı, migration gerektirmemek için). Tek tıklamada sırayla: pano yazımı başlatılır → `window.open` → pano sonucu beklenir (ikisi de kullanıcı jestinde).
- **Araç config'i:** mevcut `AI_TOOLS` kataloğuna opsiyonel `run: {webUrl, prefillUrl?, featured?}` eklendi (yeni araç sistemi yok); Perplexity ve Microsoft Copilot eklendi. `prefillUrl` `{prompt}` şablonu: ChatGPT/Claude/Grok/Perplexity/Copilot/Mistral URL ile doldurulur; Gemini/DeepSeek/Qwen ve görsel/video/ses araçları (Midjourney, Ideogram, Firefly, Suno, Runway, Luma, Kling) siteyi açar + metni panoya kopyalar. ~1800 karakteri aşan (kodlanmış) prompt URL'e konmaz, kopyalanır. `run`'ı olmayan araçlar (Cursor vb.) menüde çıkmaz. Özel URL şeması (deep link) kullanılmadı: https linkleri telefonda kurulu uygulamaya yönlenir, yoksa web açılır; şema uygulama yokken hata sayfası gösterirdi.
- **UI:** `src/features/content/run-with-ai.tsx` (`RunButton` + modal, mevcut `Modal`/`Button` token'ları; mobilde bottom sheet). Menü: tavsiye edilen (içeriğin `tools`'u) → ChatGPT/Claude/Gemini → son kullanılan; kalanı "Diğer AI araçları" altında. Prompt: araca tıklayınca anında çalışır. Generator (`preview`): üretilen prompt önizlemesi, araç seçilir (son kullanılan, yoksa tavsiye edilen önseçili), "Çalıştır" onaylar. Sonuç ekranı her durumda sonraki adımı söyler: prompt hazır açıldı / "Prompt kopyalandı, yapıştırmaya hazır" / kopyalanamadıysa metin seçili textarea + manuel kopya / pop-up engellendiyse "aracı aç" linki.
- **Yerleşim:** prompt detayında `CopyPromptButton` yanında; `PersonalizeModal` altında (çözümlenmiş metinle); generator'da `renderActions` içinde, "Prompt Olarak Aç" yetkisinden bağımsız her zaman görünür. Kartlara eklenmedi.
- **Yan düzeltme (önceden var olan hata):** `--p-success/warning/danger` yalnızca Lavanta paletinde tanımlıydı; varsayılan Kum (ve Okyanus/Orman) altında `text-danger/success/warning` sitenin her yerinde çözümlenmiyordu. Palete bağlı olmayan `:root`/`.dark` taban değerleri eklendi (`globals.css`).
- i18n: `run.*` TR+EN. **Doğrulama:** tsc/lint/build temiz; `runWithAI` mantığı tsx ile, modal ise geçici harness'le Playwright'ta (mobil 390: sıralama, öneri etiketi, "diğer araçlar", Claude URL'inin `?q=` ile açılması, panoya yazım, Gemini'de kopyala-fallback, önizleme + seçim + onay; 12/12) denendi, harness silindi. Gerçek AI sitelerinin prompt'u URL'den gerçekten kabul ettiği (siteler değişebilir) ve gerçek telefonda uygulama yönlendirmesi denenmedi.
