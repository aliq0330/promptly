Geliştiriciler

Promptly'nin herkese açık prompt kütüphanesini Claude gibi yapay zekâ araçlarına bağlayabilir ya da kendi uygulamandan okuyabilirsin. Bunlar hesap ve anahtar istemez, yalnızca herkese açık içeriği okur; kendi hesabın için kişisel anahtar bölümü aşağıda.

Claude'a bağla (MCP)

MCP, yapay zekâ araçlarının dış kaynaklara bağlanma standardıdır. Aşağıdaki adres eklenince Claude Promptly'de prompt arayabilir, tam metnini okuyabilir ve değişkenleri doldurabilir.

Bağlayıcı adresi

https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp

Claude uygulaması ve claude.ai

Ayarlar → Bağlayıcılar → Özel bağlayıcı ekle'ye gir, adı "Promptly" yap ve yukarıdaki adresi yapıştır. Kullanılabilirlik planına bağlıdır.

Claude Code

claude mcp add --transport http promptly https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp

ChatGPT

Ayarlar → Bağlayıcılar bölümünde (Gelişmiş) geliştirici modunu aç, yeni bir bağlayıcı oluştur: adı "Promptly", adres yukarıdaki, kimlik doğrulama "Yok". Menü adları sürüme ve plana göre değişir; işletme hesaplarında özel bağlayıcıya yöneticinin izin vermesi gerekebilir.

Kod editörleri ve komut satırı araçları

Her istemci adres anahtarını farklı adlandırır (url, serverUrl, httpUrl…), bu yüzden örnekler birbirinin yerine geçmez. Kendi aracına uygun olanı kopyala.

Cursor

~/.cursor/mcp.json (ya da projede .cursor/mcp.json) dosyasına ekle:

    "promptly": {
      "url": "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp"
    }
  }
}

VS Code

Projede .vscode/mcp.json dosyasına ekle:

{
  "servers": {
    "promptly": {
      "type": "http",
      "url": "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp"
    }
  }
}

Windsurf

~/.codeium/windsurf/mcp_config.json dosyasına ekle (eklenti olarak kullanıyorsan ~/.codeium/mcp_config.json):

{
  "mcpServers": {
    "promptly": {
      "serverUrl": "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp"
    }
  }
}

Gemini CLI

Tek komut yeter (ayar dosyası ~/.gemini/settings.json):

gemini mcp add --transport http --scope user promptly https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp

Codex CLI

~/.codex/config.toml dosyasına ekle (ya da codex mcp add promptly --url <adres>):

[mcp_servers.promptly]
url = "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp"

Bilgisayarında çalıştır

Uzak bağlayıcı kullanamıyorsan paketi yerelde çalıştırabilirsin (Node.js 18.17+):

claude mcp add promptly -- npx -y promptly-mcp

Claude Desktop (yerel paket)

Ayarlar → Geliştirici → Yapılandırmayı düzenle ile claude_desktop_config.json dosyasını aç ve ekle (Node.js 18.17+). Uzak bağlayıcıyı tercih edersen yukarıdaki "Claude uygulaması" adımını kullan:

{
  "mcpServers": {
    "promptly": {
      "command": "npx",
      "args": [
        "-y",
        "promptly-mcp"
      ]
    }
  }
}

Dene

Bağladıktan sonra Claude'a şunu yaz: "Promptly'de kafe logosu için bir prompt bul ve 'Kahve Durağı' için doldur." Claude şu araçları kullanır:

  • search_prompts — metin, tür, kategori, etiket ya da AI aracıyla arar
  • popular_prompts — en çok kopyalanan ya da beğenilen promptlar
  • get_prompt — tam metin, değişkenler ve yazar bilgisi
  • fill_prompt — değişkenleri doldurup son metni verir

HTTP API

Aynı veriyi kendi uygulamandan, betiğinden ya da otomasyonundan JSON olarak okuyabilirsin. Anahtar gerekmez; yalnızca GET ve doldurma isteği vardır, hiçbir şey yazılmaz.

API adresi

https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1

Prompt ara

curl "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/prompts?q=cyberpunk&content_type=image&limit=5"

Bir promptu oku

curl "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/prompts/<id>"

Değişkenleri doldur

curl -X POST "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/prompts/<id>/fill" \
  -H "Content-Type: application/json" \
  -d '{"values":{"subject":"a lighthouse"}}'

JavaScript

const res = await fetch("https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/prompts?q=logo&limit=3");
const { items } = await res.json();
console.log(items[0].title, items[0].url);

Python

import requests

res = requests.get("https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/prompts", params={"q": "logo", "limit": 3})
for item in res.json()["items"]:
    print(item["title"], item["url"])

Zapier, Make, n8n

Kodsuz otomasyon araçlarında "HTTP isteği" adımına yukarıdaki GET adresini yazman yeterli; anahtar gerekmez.

Tüm uç noktalar ve alanlar için OpenAPI belgesi: openapi.json

Hesabınla kullan (kişisel anahtar)

Yukarıdakiler herkese açık içeriği okur. Kendi promptlarına (özel taslaklar dahil) erişmek ya da hesabına özel taslak eklemek için bir kişisel anahtar oluştur: Ayarlar → Geliştirici anahtarları. Anahtar yalnızca senin hesabında çalışır.

Anahtar oluştur

Kim olduğunu doğrula

curl "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/me" \
  -H "Authorization: Bearer pmt_YOUR_KEY"

Kendi promptlarını listele (özel taslaklar dahil)

curl "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/me/prompts?status=draft&limit=10" \
  -H "Authorization: Bearer pmt_YOUR_KEY"

Hesabına özel taslak ekle

Gövde, sitedeki “Dışa aktar”ın JSON dosyasıdır (en çok 30 prompt, 64 KB). Yazma anahtarı ister; sonuç HER ZAMAN özel taslaktır, hiçbir şey yayınlanmaz. ?dry_run=true yalnızca doğrular.

curl -X POST "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/api/v1/me/prompts" \
  -H "Authorization: Bearer pmt_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d @promptly-prompts.json

Kişisel MCP (Claude Code, Cursor…)

Aynı anahtarla kendi promptlarını yapay zekâ aracından kullan: list_my_prompts, get_my_prompt, list_my_saved ve (yazma anahtarıyla) save_prompt_draft. Adres yukarıdakinden farklıdır:

https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp/me
claude mcp add --transport http promptly-me https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp/me \
  --header "Authorization: Bearer pmt_YOUR_KEY"

Cursor ve diğer istemciler

{
  "mcpServers": {
    "promptly-me": {
      "url": "https://xqxybhjcyrvaroknucdq.supabase.co/functions/v1/mcp/me",
      "headers": {
        "Authorization": "Bearer pmt_YOUR_KEY"

claude.ai ve ChatGPT bağlayıcıları sabit bir başlık gönderemez; onlar için hesabınla giriş (OAuth) ayrıca hazırlanıyor. Anahtarı bu araçlara yapıştırma.

Anahtar kuralları

  • Anahtar şifre gibidir: kimseyle paylaşma, depoya ya da ekran görüntüsüne koyma. Sızdığını düşünürsen Ayarlar'dan hemen iptal et.
  • Okuma anahtarı yalnızca okur. Yazma anahtarı hesabına yalnızca özel taslak ekleyebilir; yayınlayamaz, silemez.
  • Hesap başına sınır: okumada dakikada 120, yazmada dakikada 30 istek (aşarsan 429). Hesabın askıdaysa anahtar çalışmaz.
  • Yanıtlar kişiseldir ve önbelleğe alınmaz.

Bilmen gerekenler

  • Herkese açık uçlar salt okunurdur: Promptly'ye hiçbir şey yazılmaz ve hesabına erişilmez (kişisel anahtarla yapılanlar yukarıdaki bölümdedir).
  • Yalnızca yayında ve herkese açık promptlar gelir; özel, taslak ve topluluğa özgü içerik dışarıda kalır.
  • Her prompt yazar atfıyla (source) gelir. Paylaşırken ya da yeniden kullanırken atfı koru.
  • Prompt metinleri kullanıcı içeriğidir. Bir yapay zekâ aracına ya da otomasyona vermeden önce kontrol et.
  • Adil kullanım: API için IP başına dakikada yaklaşık 60 istek (bağlayıcı/MCP sınırı daha geniştir). Aşarsan 429 ve Retry-After başlığı gelir; sınır yaklaşıktır ve değişebilir. Yoğun ya da toplu çekme planlıyorsan önce bize yaz.
